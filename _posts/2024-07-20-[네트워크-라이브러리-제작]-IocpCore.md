```c++
/*----------------
	IocpObject
-----------------*/

class IocpObject : public enable_shared_from_this<IocpObject>
{
public:
	virtual HANDLE GetHandle() abstract;
	virtual void Dispatch(class IocpEvent* iocpEvent, int32 numOfBytes = 0) abstract;
};

/*--------------
	IocpCore
---------------*/

class IocpCore
{
public:
	IocpCore();
	~IocpCore();

	HANDLE		GetHandle() { return _iocpHandle; }

	bool		Register(IocpObjectRef iocpObject);
	bool		Dispatch(uint32 timeoutMs = INFINITE);

private:
	HANDLE		_iocpHandle;
};
```
{% endraw %}



이 코드는 Windows 환경에서 IOCP (Input/Output Completion Port)을 사용하여 비동기 IO를 관리하는 클래스들을 정의하고 있습니다.


IOCP는 주로 네트워크 서버나 다중 스레드 환경에서 비동기 입출력 작업을 처리할 때 사용됩니다.



#### `IocpObject` 클래스



{% raw %}
```c++
/*----------------
    IocpObject
-----------------*/

class IocpObject : public enable_shared_from_this<IocpObject>
{
public:
    virtual HANDLE GetHandle() abstract;
    virtual void Dispatch(class IocpEvent* iocpEvent, int32 numOfBytes = 0) abstract;
};
```
{% endraw %}


- `IocpObject` 클래스는 추상 클래스로, `enable_shared_from_this`를 상속받아 자체를 `shared_ptr`로 관리할 수 있도록 합니다.
- `GetHandle()` 메서드는 순수 가상 함수로, 파생 클래스에서 구현해야 하는 가상 함수입니다. IOCP에서 핸들을 얻는 데 사용됩니다.
- `Dispatch()` 메서드도 순수 가상 함수로, IOCP 이벤트를 처리하는 데 사용됩니다. `IocpEvent`와 관련된 작업을 수행하며, `numOfBytes`는 이벤트와 관련된 바이트 수를 나타냅니다.


#### `IocpCore` 클래스



{% raw %}
```c++
/*--------------
    IocpCore
---------------*/

class IocpCore
{
public:
    IocpCore();
    ~IocpCore();

    HANDLE GetHandle() { return _iocpHandle; }

    bool Register(IocpObjectRef iocpObject);
    bool Dispatch(uint32 timeoutMs = INFINITE);

private:
    HANDLE _iocpHandle;
};
```
{% endraw %}


- `IocpCore` 클래스는 IOCP의 핵심을 담당하는 클래스입니다.
- 생성자(`IocpCore()`)와 소멸자(`~IocpCore()`)가 정의되어 있습니다.
- `GetHandle()` 메서드는 IOCP 핸들을 반환합니다.
- `Register()` 메서드는 `IocpObjectRef` 객체를 등록하는 함수입니다. 여기서 `IocpObjectRef`는 `shared_ptr<IocpObject>` 형태일 것으로 추정됩니다. 이 함수는 IOCP에 관련된 객체를 등록하여 이벤트를 받을 준비를 합니다.
- `Dispatch()` 메서드는 IOCP 이벤트를 처리하는 함수입니다. `timeoutMs` 매개변수는 이벤트를 대기할 최대 시간을 밀리초 단위로 지정합니다. 기본값은 무한(INFINITE)입니다.


#### 요약


이 코드는 Windows의 IOCP를 이용하여 비동기 IO를 관리하기 위한 클래스들을 정의하고 있습니다. `IocpObject` 클래스는 추상 클래스로, IOCP에서 이벤트를 처리할 객체들이 구현해야 하는 인터페이스를 제공합니다. `IocpCore` 클래스는 이러한 객체들을 등록하고 이벤트를 처리하는 핵심 역할을 수행합니다.
