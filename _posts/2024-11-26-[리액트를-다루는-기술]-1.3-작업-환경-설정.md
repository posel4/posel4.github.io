NVM(Node Version Manager)을 사용하면 Node.js 버전을 관리하고 설치할 수 있다.


---



## Node.js



#### 1. **NVM 설치**


NVM이 설치되어 있지 않다면 먼저 설치해야 한다.



#### **MacOS/Linux**



{% raw %}
```shell
curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.39.5/install.sh | bash
```
{% endraw %}



설치가 끝나면 NVM을 로드해야 한다.



{% raw %}
```shell
export NVM_DIR="$([ -z "${XDG_CONFIG_HOME-}" ] && printf %s "${HOME}/.nvm" || printf %s "${XDG_CONFIG_HOME}/nvm")"
[ -s "$NVM_DIR/nvm.sh" ] && \. "$NVM_DIR/nvm.sh"  # This loads nvm
```
{% endraw %}




#### 2. **Node.js 설치**


NVM이 설치된 후, 아래 명령어로 원하는 Node.js 버전을 설치할 수 있습니다.



{% raw %}
```shell
nvm install <version>
```
{% endraw %}




{% raw %}
```shell
nvm install 18.17.1
```
{% endraw %}



**LTS 버전 설치:**



{% raw %}
```shell
nvm install --lts
```
{% endraw %}




#### 3. **Node.js 버전 설정**


설치한 Node.js 버전을 기본으로 설정하려면:



{% raw %}
```shell
nvm use <version>
```
{% endraw %}



기본 버전으로 고정하려면:



{% raw %}
```shell
nvm alias default <version>
```
{% endraw %}




#### 4. **설치 확인**


Node.js와 NPM이 제대로 설치되었는지 확인하려면:



{% raw %}
```shell
node -v
npm -v
```
{% endraw %}




#### 5. **Node.js 버전 관리**


설치된 Node.js 버전을 확인하려면:



{% raw %}
```shell
nvm list
```
{% endraw %}



다른 버전으로 전환하려면:



{% raw %}
```shell
nvm use <version>
```
{% endraw %}

## Yarn


Mac에서 Yarn을 설치하는 방법은 여러 가지가 있지만, 아래 방법들이 가장 흔히 사용된다.


Yarn은 Node.js 기반 패키지 매니저로, NPM보다 빠르고 효율적으로 동작한다.


---



#### 1. **Homebrew로 설치**

1. **Homebrew 설치 확인**
Homebrew가 설치되어 있지 않다면, 다음 명령어로 설치:

	
{% raw %}
```shell
	/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
```
{% endraw %}


1. **Yarn 설치**
Homebrew를 사용해 Yarn을 설치:

	
{% raw %}
```shell
	brew install yarn
```
{% endraw %}


1. **설치 확인**
Yarn이 올바르게 설치되었는지 확인하려면:

	
{% raw %}
```shell
	yarn --version
```
{% endraw %}




#### 2. **NPM으로 설치**

1. **Yarn 설치**

	
{% raw %}
```shell
	npm install -g yarn
```
{% endraw %}


1. **설치 확인**

	
{% raw %}
```shell
	yarn --version
```
{% endraw %}




#### 3. **Yarn 공식 설치 스크립트 사용**

1. **스크립트 실행**
터미널에서 다음 명령어를 실행하세요:

	
{% raw %}
```shell
	curl -o- -L https://yarnpkg.com/install.sh | bash
```
{% endraw %}


1. **환경변수 설정**
설치 스크립트가 Yarn을 `$HOME/.yarn/bin`에 설치합니다. 따라서 환경변수를 설정해야 합니다:

	
{% raw %}
```shell
	export PATH="$HOME/.yarn/bin:$PATH"
```
{% endraw %}


1. **설치 확인**

	
{% raw %}
```shell
	yarn --version
```
{% endraw %}




#### 4. **Corepack 사용**

1. **Corepack 활성화**

	
{% raw %}
```shell
	corepack enable
```
{% endraw %}


1. **Yarn 설치**

	
{% raw %}
```shell
	yarn --version
```
{% endraw %}
